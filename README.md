# nord-marp-theme

[Nord](https://www.nordtheme.com/) theme for [Marp](https://marp.app/).

## Demo

<https://ansanloms.github.io/nord-marp-theme/slides.html>

## Light theme

Add `<!-- class: light -->` to a slide (or `class: light` in the front-matter for the whole deck) to switch that slide to the Snow Storm ground. Frost accents fall below 4.5:1 on a light ground (nord10 is 3.5:1), so links read only at body size.
